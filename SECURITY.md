# Security Policy

## Scope

This repository is an educational demonstration of pre-deployment Terraform security checks. It is not a managed service or a certification of a deployed environment.

## Reporting a vulnerability

Please avoid publishing sensitive exploit details in a public issue. Contact the repository maintainer through the GitHub profile and provide a concise description, impact, reproduction steps, and suggested mitigation.

## Safe-use guidance

- Never commit credentials, state files, or production plan artifacts.
- Review scanner output and policy exceptions rather than suppressing findings without analysis.
- Validate controls against your architecture and applicable security requirements before production use.
